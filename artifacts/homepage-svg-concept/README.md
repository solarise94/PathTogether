# 组织导航 SVG 概念预览

依据用户提供的组织参考图绘制的结构示意，未对图片做矢量描摹，也未作病理类型判定。

## 查看

直接打开 `preview.html`：单文件包含样式、组织生成器与镜头动画，无外部依赖、无需联网。
`tissue.svg` 是同一画面的独立静态 SVG，可用矢量软件打开。

## 形态

- 固定随机种子 149336，84 个不等大小、不规则轮廓的腺体，以距离约束形成自然堆积。
- 每个腺体包含连续细胞壁与中心腔隙，细胞围绕腔隙排列。细胞核大小、长短、角度、位置、颜色有受控变化；浅色胞内区域不均匀分布。
- 腺体之间有弯曲纤维和稀疏梭形细胞核。全图没有内嵌位图、噪声滤镜或外部字体。
- 画面是简化示意，未声称为真实切片或模型分析结果。

## 流程

全景 → 局部 A → 细节 A → 标注 A → 拉远并切换局部 B → 细节 B → 标注 B → 全景回看。

使用同一 SVG 的 viewBox 改变观察范围；标注始终在原组织坐标，动画不重建细胞。提供暂停、继续、前后步进、重播。离开可见区或切到后台暂停；减少动态效果偏好下默认显示最终静态回看。

## 体积与边界

HTML/CSS/JS 完整动态预览约 21 KB，gzip 总和约 9 KB。这是本地文件编码体积，不是线上传输测量。
展开后的静态 SVG 约 1.43 MB，gzip 约 264 KB；因此接入主页时应使用小体积生成器，而非传输展开后的所有节点。浏览器需要渲染约一万个 SVG 节点；手机真实设备上的流畅度仍应在正式接入前评估。

`verification.json` 记录流程、形态稳定、无位图请求、暂停、减少动态效果、双标注、手机边界和跨刷新随机种子一致性等检查。

本次仅产生独立概念预览，未修改主页业务文件或线上版本。

## 标注交互更新

标注阶段正文以每字约 60ms 的速度模拟流式输出（本地动画，不发起 SSE 请求）；播放暂停、后台暂停时文字也停止。标题与正文依次输出，先停顿约 350ms。手动步进到标注时也从空文本开始输出，完成后留在当前标注；减少动态效果默认仍显示最终静态回看。回看全景同时保留两个组织坐标框及屏幕字号固定的文字标签，手机上仍能读清。
