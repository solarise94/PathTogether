# Viewer 文件夹体验实现交接

日期：2026-10-13。状态：待实施。以最新 `origin/main` 加本次 closeout 为基线；不要从根目录旧 `slide-id-refactor` 分支开工。

## 用户能看到的变化

在“病例 A / 肺组织”中上传，默认加入肺组织文件夹；用户仍可主动改成其他目录或未归类。刷新后恢复当前目录和页码；通过链接或搜索打开切片时，侧栏优先定位该切片，不被旧目录记忆覆盖。切片卡片的分页、堆叠和翻牌动画沿用现有行为。

现状并非没有目标目录功能：`static/app.js` 已有 `importTargetState`、`renderImportTargetSelects`、`syncImportTargetFromSelect`、`importAssociateUploaded`，本机转换交接也通过 `convertHandoffTarget` 携带目标。目前默认目标与 `fbState.folder` 分离；`fbState.pages` 只保存在内存。

## 1. 当前目录上传默认值

代码入口：`openImportDrawer`、`fbPlusMenu`、`fbProject`、`fbState`、`renderImportTargetSelects`，本地上传与百度导入的下拉选择均在 `static/app.js`。

推荐规则：

1. 一次打开抽屉视为一次新的导入选择会话。进入时读取当前真实文件夹 ID；根目录与临时查看集合默认未归类。只有最新授权项目列表中的目录可作为默认值。
2. 目录列表异步返回后才设置下拉和 `importTargetState`，沿用已有服务端权限检查。若用户已操作下拉，迟到的目录请求不得覆盖其选择；用抽屉 generation 或交互 dirty 标志区分。
3. 用户主动选择不同目录、未归类或新建目录之后，在本次导入会话内保持选择。切片上传开始时冻结目标；后续切换侧栏目录不能改变已在传任务的归属。
4. 一次上传结束后的目标关联沿用 existing receipt、slide ID 和幂等键；失败保留切片与重试入口，不自动改成当前目录，也不重传已发布切片。
5. 百度导入可以沿用相同默认选择规则，但不得改动已有批次的目标；本机转换 handoff 必须冻结同一目标，不让工具页重新猜目录。

“当前目录不是我的目录/已失去写权限”时，仅可查看不能默认写入。现有项目数据若没有足够的可写信息，先完善返回字段或保留显式选择，不能用“列表里看得到”推断可写。

## 2. 刷新恢复与隔离

建议使用小型、版本化的 localStorage 记录，不新增后端表：

```json
{"v":1,"folder":"project-id-or-null","pages":{"root":0,"project-id":1},"updatedAt":0}
```

- key 按实际登录身份隔离；使用现有 `currentUserId`，并考虑管理员预览的有效身份与 actor。没有可信身份时不持久化。两个域名分别存储，不跨域同步。
- 建议最近 30 天、最多 100 个目录；只存 ID、页码、时间，不能存名称、缩略图、切片列表或访问 token。
- 身份和授权项目列表加载完才恢复；目录不存在、已删除或已撤权则回根目录；页码必须经现有 `fbPackPages` 的实际页数裁剪。
- 优先级：URL `?slide=` / 本次搜索定位 > 本次用户导航 > 磁盘记忆。复用 `fbLocateSlide`，不能再写第二套文件夹/页码计算。
- 导航和翻页结束时保存；storage 异常或隐私模式下继续使用内存，不阻断用户。刷新、注销、切账号、删除目录都要有明确恢复规则；换账号绝不读取上一账号的目录。
- 目录列表迟到时，不把已经由深链接定位成功的侧栏拉回旧记录。记忆恢复只在初始化时尝试一次。

## 3. 实施拆分

1. 抽出记忆读取/校验/裁剪/写入的薄模块或函数，接到 `fbGo` 与翻页，不改列表分页算法。
2. 在 `loadAll` 的身份、projects/slides 准备阶段接入恢复，明确深链接优先级。
3. 抽屉打开时设置默认目标，保护手动操作和请求时序；复用本地、转换、百度的现有目标合同。
4. 加回归和真实浏览器验收，更新用户指南中的目录说明。不要给常用 UI 增加额外设置页。

## 4. 必须覆盖的案例

| 情景 | 预期 |
|---|---|
| 进入子目录第 2 页后刷新 | 恢复同一目录和合法页码 |
| 第 3 页只剩两页 | 裁剪到最后一页，不出现空白列表 |
| 记忆目录被删除/撤权 | 回根目录，不请求未授权目录内容 |
| 从另一个目录的记忆状态打开切片深链接 | 定位链接切片及其真实页码 |
| 上传开始后侧栏切换目录 | 上传目标保持开始时的值 |
| 用户改目标，之后 projects 请求才返回 | 不覆盖用户选择 |
| 明确选择未归类后上传 | 不被当前文件夹默认值覆盖 |
| 目标关联失败、刷新后重试 | 沿用原 slide ID/回执，只重试原目标 |
| 用户 A 注销后用户 B 登录 | B 看不到 A 的导航记忆或目标 |
| localStorage 不可写 | 导航和上传仍可使用 |
