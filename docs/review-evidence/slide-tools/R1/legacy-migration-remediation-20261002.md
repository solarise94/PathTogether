## 7. 生产窗口草案（约 40–50 分钟停服，晚间）

0. 窗口前（不停写、只读）：生产在线审计，与演练结果比对（新增的 R1 后切片只应出现在 out-of-scope）。
1. 停写：停止 pathtogether-demo 与 histopilot-demo（容器内全部 writer 随之停止）；确认无在途上传/删除任务。
2. 备份：DB 全量转储 + sha256；上传目录硬链接快照（工具不修改源文件，硬链接防误删）。
3. （若决定 1a）3 行归属登记。（若决定 2 恢复）文件放回原位并校验。
4. 回填 `--apply` → 冻结审计 → `plan --env prod`（计划 digest 记入发布单）。
5. 物理迁移 `--apply --plan-digest … --env prod --quiesce-proof <停写证据>`（预计约 12 分钟）。
6. 终验 `verify --quota-approvals <用户核准文件>`，退出码 0 才继续。
7. 部署 PT r1-rc4（先私有端口验收），再部署 HP 0.3.5 与插件 0.3.5（PT 先、HP 后）。
8. 浏览器验收：站长工作区 3 张授权切片；后台「加入」新/旧切片各一张后收回；项目打开、标注可见；Demo；AI slide_info（新上传 + 迁移切片各一）。
9. 开放读写；逐 worker 恢复并看健康检查。

回滚边界：开放读写前，可停服并用第 2 步的转储恢复数据库（窗口内无新写入，不覆盖任何用户数据）；
`objects/` 中新增的迁移副本可按 journal 清理，源文件始终保留。开放读写后只能前滚修复。
