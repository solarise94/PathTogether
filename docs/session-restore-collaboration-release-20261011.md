## 修复后的行为

初始化期间，切片先到而 AI 配置后到时，原恢复函数因配置未就绪直接返回。
配置成功后没有重试，所以服务器中的会话仍存在，浏览器目录却一直为空。

修复在 HistoPilot `integrations/pathtogether/ui/main.js`：记录待恢复切片的稳定 ID、
切片 epoch 和选择 generation，配置就绪后只恢复当前切片。配置期间 A→B 切换，
只恢复 B；用户已新建草稿或改变会话选择时，仅刷新目录，不覆盖用户当前选择。
配置先到的路径仍只恢复一次。

另外修正了离开切片时的草稿保存：直接读取 outgoing 切片的稳定 ID，
不再用 incoming 切片是否有旧文件名判断。ID-only 切片之间切换也保留未发送草稿。

新增五项回归：

1. 切片先到、配置后到，恢复正确 ID 的会话。
2. 配置先到，打开切片只恢复一次。
3. 同名 A/B 切片在配置等待期间切换，只恢复当前 B。
4. 配置等待期间新建并输入草稿，保留文字和选择，同时加载目录。
5. 没有旧文件名的 ID 切片往返，未发送草稿按原切片 ID 保留。

配置竞态回归在原实现上有 2 项失败；ID-only 草稿回归也确认在原文件名判断上失败。
修复后原断言通过，HistoPilot 全套 1550 项通过。

## 首页模块

- 标题采用用户指定文案，提供“开始协作”入口及导航锚点。
- 说明真实已支持的流程：设置分享链接的查看/标注权限和有效期，按作者区分
  标注，把问题和观察写在对应区域的备注中，供同伴复核、补充自己的标注。

  参与者；右侧展示各自备注。没有把尚未集成的独立即时聊天展示为产品能力。

  `prefers-reduced-motion` 默认呈现静态完整标注，仍可手动选步骤。
- 每轮只改变局部变换、轮廓与透明度，不逐帧请求图片或运行模型。
  桌面与手机分别排版，控制按钮最小高度 44px，提供中英文内容。
