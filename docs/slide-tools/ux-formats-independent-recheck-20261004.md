## 代码判断与范围

- 分配前资源预算已接入 MRXS probe/convert；原位置表分配在提交内存前被拒绝。该合成负例不能证明所有输入或真实低内存设备上的峰值。
- 续跑使用任务记录固定身份，并检查 journal 一致性；重新枚举成员、读取实际字节计算摘要后比较，不再以可替换的磁盘 manifest 自证。
- MRXS 低倍层读取已提交的上一输出层，以盒式平均生成；续跑读取同一份输出，避免重新使用扫描仪低倍拼接坐标。边缘沿现有 floor 层尺寸定义处理，不足一个降采样像素的最右/下边缘不进入该低倍层；全分辨率不受此规则影响。
- 低倍层有 JPEG 重编码，故不能将“几何对齐”写成与 OpenSlide 或 L0 的像素无损一致。真实样本差异数值、速度及体积变化本轮没有重新测量。
- GT 检查仍有明确的高成本 ROI 跳过分支；本轮关闭的是原缺失/空 L0/L1 参考材料假通过负例，不将测试框架的 passed 总数解释为每个真实 ROI 都已执行。
