# Viewer 与管理后台舒适密度优化（2026-10-09）

基于 `admin-viewer` 的 `a38bde59`。本次调整可读性、点击区域和响应式收纳，不修改注册、权限、数据库或切片数据。

## 最终交互

- Viewer 桌面主要按钮从 22–28px 提升至 40px；手机主要操作为 44px。桌面顶栏由 52px 调为 60px，仍保持单行，空间不足时低频操作进入「更多」。搜索、分享和账户优先留在主栏。
- 正文与操作文字以 14px 为主，辅助信息 13px；提高灰色文字对比度。搜索、分享、账户浮层，AI 输入/发送按钮及键盘焦点提示同步调整。
- 左栏从 176px 加宽至 224px，切片整卡 128px、露出条带至少 44px，文件夹卡 64px。分页预算与实际 CSS 同步，仍最多八项一页。底部账户入口两列排列，避免放大按钮后挤占切片空间。
- 修正侧栏层叠顺序，使悬停滑出的缩略图完整显示在画布之上。
- 手机将旋转、画质、绘制和保存等工具收入「更多」，选择绘制工具后可直接在画布操作。修正浮层展开时误计工具栏宽度、导致关闭菜单后搜索/分享消失的问题。
- 后台表格文字提升至 14px，行内操作与常规按钮使用相同点击高度。手机用户和切片记录按卡片排布，保留所有原有信息和操作，避免时间字段逐字折行。
- 管理插件版本 `0.4.17`，同步文件摘要及 source-policy pin。上线时必须与新版主应用配套发布并重启服务；本次无数据库迁移。
