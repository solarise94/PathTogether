    测试申请

    已验证邮箱的待激活用户在此申请测试资格：研究方向与自愿数据分享选择（分享与否不影响审批）。通过即激活账号并按新用户默认总额度发放额度（终态，不可撤销）；拒绝同样终态并邮件通知用户。通过前请先确认「设置」页已配置新用户默认总额度，否则无法发放。用户若凭邀请码直接激活，其申请会自动收口为「已通过邀请码激活」（非人工审批，无法再审核）。

    研究删除任务

    研究副本删除任务（撤回/用户申请产生）由后台 worker 异步执行：失败有界重试，重试耗尽后转为终态 failed 待人工处置。此处唯一操作是「重新执行删除」：任务复活为 pending 并重置尝试次数，由 worker 重新清理——completed 状态只能由实际清理成功产生，本页不提供也不存在「直接标记完成」的入口。删除义务了结前研究侧持续阻断，与用户正常读片无关。
