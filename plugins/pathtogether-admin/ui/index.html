    注册模式

    closed=关闭注册；invite_only=邀请码注册（需 HTTPS、Secure Cookie、PostgreSQL 前置条件）。public 本阶段不支持（单独安全评审前不可选）。保存经服务端校验并写审计。

    金额策略（nano-CNY wire；输入按 CNY 精确换算）

    默认修改只影响之后新建的窗口（已开窗口额度固定）；要立即影响当前周期，用下方「调整当前窗口」（独立操作 + 二次确认 + 审计）。金额输入/输出均为十进制字符串换算，超过 JS 安全整数也不失真。

    运行时安全参数

    「放开次数限制」不等于取消安全限制（§1.2）：Demo 开关、单任务最大步骤、并发与短窗口速率仍生效。Demo IP 桶当前为 24 小时窗口的 env 配置（只读展示；改造为短窗口请求速率属批次 E）。

    当前窗口（立即生效的单独操作）

    调整只改当前窗口的额度快照：已消费/预占不回退；调低到低于已消费后，下一次预占即被拒绝。需二次确认并写审计；窗口版本冲突（409）时刷新后重试。

    历史影子数据（不参与硬额度）

    价格单位修复（批次 A cutover）之前的用量按旧错误价格计价，属历史影子数据：不参与任何当前金额额度/窗口/余额，不与修复后的金额混合汇总。当前周期金额请看「设置」页的金额策略与当前窗口。
