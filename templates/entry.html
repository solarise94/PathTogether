产品

产品如何工作

01

打开切片

把 WSI 放进 PathTogether。想先看效果，可以从 Demo 展示入口进入。

02

让 HistoPilot 导航

Agent 先高倍观察，再低倍识别，必要时调用分析插件；步骤有上限。

03

协作与分享

登录后上传自己的切片、标注、评论，按权限分享。

原理

Agent 怎么读一张切片

先点「播放原理」看高倍观察再低倍识别；再点「播放插件」看 Agent 如何把视野交给你自己部署的分析插件。

50 µm 20×

准备播放：先高倍看清细胞，再退到低倍识别结构。

  1. 高倍 20×：看细胞核与局部细节
  2. 平移到相邻视野，继续确认
  3. 拉远到 2×：识别腺体与组织结构
  4. 留下可复查的观察轨迹
  1. Agent 选定当前视野
  2. 调用你部署的分析插件
  3. 插件返回计数 / 区域结果
  4. 能力边界由插件扩展，不改导航内核

抽象示意，不是真实切片，也不构成诊断。

能力

核心能力

Agentic 导航

高倍观察、低倍识别、坐标语义、快照与视觉预算。

协作 Viewer

OpenSlide + OpenSeadragon，项目、ROI、评论。

自研分析插件

部署自己撰写的分析插件，扩展能力边界；HistoPilot 只负责导航与调用。
