开始

如何开始

  1. 1

    注册账号

    {% if registration_mode == "closed" %}

    暂未开放注册。已有账号可直接登录；没有账号也可以先体验 Demo。

    {% elif registration_mode == "invite_only" %}

    使用管理员发放的邀请码创建账号。

    {% elif registration_mode == "public" %}

    验证邮箱并设置密码，即可创建账号。

    {% else %}

    验证邮箱并提交申请，管理员审核通过后即可使用。

    {% endif %}
  2. 2

    登录工作台

    使用你的账号登录，进入个人工作台。

  3. 3

    上传切片

    在工作台导入自己的切片文件，等待处理完成。

  4. 4

    查看与分析

    打开切片，查看、标注，并使用 AI 与测量工具辅助分析。

没有账号也可以先体验 Demo（无需登录）。
